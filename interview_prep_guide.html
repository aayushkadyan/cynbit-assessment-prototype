1. Executive Summary & Problem Analysis

Cynbit Technologies (cynbit.in) is an IT services and software solutions firm based in Jaipur specializing in AI automation, autonomous agents, and high-performance software.

The Discovery Friction Point

While the website features sophisticated aesthetics and clear service categories, the conversion mechanism on /contact suffers from a major drop-off point:

  • Blank Canvas Paralysis: The current form features 5 passive fields (Full Name, Email, Company, Industry, Message). Visitors must articulate technical scope without guidance.
  • Zero Immediate Value: Submitting leads to a static confirmation; users wait 24–48 hours for a sales response.
  • High Sales Overhead: Cynbit sales engineers receive unstructured text requiring multiple discovery calls just to qualify budget, timeline, and capabilities.

The Proposed Solution: Smart Project Scoping Assistant

An intelligent, 6-step interactive discovery wizard that replaces passive inputs with guided options, executes real-time heuristic lead scoring, and immediately outputs a personalized Project Scope Brief.

2. Technical Stack Explained (Plain English)

Here is how to explain the technologies used even if you are newer to them:

1. Next.js 15+ (App Router)

What is it? A React framework developed by Vercel that handles routing and optimization out of the box.
How it's used in your project:

  • app/page.tsx: Serves as the homepage component.
  • app/layout.tsx: Wraps the application with global fonts (Material Symbols) and metadata.
  • app/globals.css: Stores CSS design tokens and custom gradient animations.
  • "use client": Placed at the top of interactive components (like ScopingAssistant.tsx) because they use user clicks and state variables.

2. TypeScript

What is it? JavaScript with type safety. It prevents bugs by ensuring variables hold the expected data structures.
How it's used in your project:

  • interface FormData: Ensures every user selection (goal, budget, timeline, email) matches strict types.
  • interface Step: Defines questions, answer options, and icons cleanly.

3. Tailwind CSS v4 & PostCSS

What is it? A utility-first CSS framework allowing rapid, maintainable design.
How it's used in your project: Matching Cynbit's production design tokens: indigo-600 primary color, slate-900 dark backgrounds, rounded-3xl cards, and glassmorphic navigation bars. Compiled via @tailwindcss/postcss.

3. Core Code Architecture Walkthrough

A. Lead Scoring Heuristic (`ScopingAssistant.tsx`)

function computeScore(data: FormData) {
  let score = 0;
  // 1. Budget Scoping (Up to 40 pts)
  if (data.budget === "500k_plus") score += 40;
  else if (data.budget === "200k_500k") score += 30;
  else if (data.budget === "50k_200k") score += 20;

  // 2. Timeline Urgency (Up to 30 pts)
  if (data.timeline === "asap") score += 30;
  else if (data.timeline === "1month") score += 20;

  // 3. Multi-Service Scope (Up to 20 pts)
  if (data.services.length >= 3) score += 20;
  else if (data.services.length >= 1) score += 10;

  // 4. Context Depth (Up to 10 pts)
  if (data.details.length > 100) score += 10;

  // Tier classification
  if (score >= 70) return { score, label: "High Priority", color: "emerald" };
  if (score >= 40) return { score, label: "Qualified Lead", color: "amber" };
  return { score, label: "Exploring", color: "blue" };
}
